## Adding the next case

Case studies live in `case-studies/`, one file per case, named
`NN-short-slug.md` (increment NN from the last one added).

1. Copy `case-studies/_template.md` → `case-studies/NN-short-slug.md`.
2. Fill the three beats (same shape as Week 2):
   - **Problem** — what was broken, unclear, or worth solving. 1–2 lines.
   - **What I did** — the approach and tools, naming the one place AI
     did real work, not just autocomplete.
   - **What came of it** — the concrete result: a number, a decision it
     changed, or a working artifact that didn't exist before.
3. Link the actual notebook/repo/output backing the claim, so it's
   checkable, not just asserted.
4. Add a row to the case-studies table above.
5. Commit: `case: <slug>`.

Budget ~20–30 minutes if the underlying work is already done — this
step is documentation, not new analysis.
